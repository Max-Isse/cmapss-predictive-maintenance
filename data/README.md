## What it is

- **Format:** four sub-datasets, FD001–FD004 (operating conditions × fault modes). Each has a training file
  (engines run to failure), a test file (engines stopped some time before failure) and a file with the true
  remaining useful life (RUL) of each test engine.
- **Rows:** each row is one operating cycle of one engine, with 26 space-separated numbers: unit, cycle,
  3 operational settings and 21 sensor measurements.

| Set | Conditions | Fault modes | Train engines | Test engines | Train rows | Test rows |
|---|---|---|---|---|---|---|
| FD001 | 1 | 1 (HPC) | 100 | 100 | 20,631 | 13,096 |
| FD002 | 6 | 1 (HPC) | 260 | 259 | 53,759 | 33,991 |
| FD003 | 1 | 2 (HPC, fan) | 100 | 100 | 24,720 | 16,596 |
| FD004 | 6 | 2 (HPC, fan) | 249 | 248 | 61,249 | 41,214 |

Engine counts are from the files. NASA's `readme.txt` states FD004 the other way round (248 train, 249 test). The
files are internally consistent: 248 test engines and 248 RUL values.

## What a simulation means for claims

C-MAPSS is generated by a thermodynamic engine simulation with injected, exponentially growing degradation and
added sensor noise; it is not fleet data. It is the standard public benchmark, so methods and metrics can be
compared with published work. But real engines have maintenance actions, sensor faults, missing data, varying
missions and censored histories that this data does not contain. Any cost or accuracy figure in this project is
an estimate on simulated data and does not transfer to a real fleet without validation on real records.

## Layout

- `raw/download/` — archive as downloaded (git-ignored); `raw/cmapss/` — extracted text files.
- `landing/text/`, `landing/parquet/` — files waiting for ingestion (D-005); `landing/replay/` (phase 4).
- `lakehouse/{bronze,silver,gold}/` — Delta tables (git-ignored, rebuilt by the pipeline).

## Synthetic data

- **Phase 4 (planned):** a **SYNTHETIC REPLAY** that feeds real test-set engines into the landing zone cycle by
  cycle, as if they were arriving from the fleet. The values are real; only the arrival timing is simulated. It
  will be labelled as such in the lineage.
- **Tests:** `tests/fixtures/` holds hand-built files in the NASA format (2 engines, random sensor values) used
  only to test code.
